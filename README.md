# 物语 · 家庭储物台账

家里每件东西，都该有个地址。

## 下载

**最新版：** 见 [Releases](https://github.com/miao010101/wuyu-releases/releases/latest)

装好之后，以后升级不用再来这里：App 里 **设置 → 关于 App → 检查更新**，
检测到新版会直接「下载并安装」。

## 安装说明

1. 下载 `wuyu-x.y.z.apk`
2. 点开安装，系统会问「允许从此来源安装应用」→ 允许一次即可
3. 装好后所有数据都存在你自己手机上（本地 SQLite + 私有目录），没有服务器，也不会上传

## 更新会不会丢数据

不会。所有版本都用同一套签名，覆盖安装直接保留数据。
（也正因如此，请不要从别的渠道装「改了签名」的物语，否则只能卸载重装。）

## 这个仓库放什么

只放 APK 和版本信息（`latest.json`），不含源码。
